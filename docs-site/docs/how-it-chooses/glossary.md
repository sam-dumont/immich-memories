# Useful words

| Word | Meaning |
|---|---|
| **Moment** | Pictures of one short stretch of activity. |
| **Story** | Related moments given a share of the film. |
| **Draft / cut** | The chosen shots, before they are rendered. |
| **Revision** | Your saved changes to an existing cut. |
| **Sharing level** | Who the film is intended for: just us, family or anyone. |
| **Hold** | A reason a picture is kept out at a sharing level. You can review and clear it. |
| **Tier** | The models available to the app: Basic, GPU or Full. Automatic is the default. |
| **Reader** | A text model that reads descriptions and library facts; hosted readers receive that text outside your network. |
| **Laya** | The small local text classifier that checks captioned activities on GPU and Full. |
| **Rules draft** | The initial cut from dates, places, favourites, people and picture facts, without a prose model. |
| **Banked** | A result already saved, so a later run can reuse it. |

The [technical glossary](../reference/selection-internals/glossary.md) covers the terms used in diagnostics and selection internals.
