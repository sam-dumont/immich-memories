    autonumber

    You->>App: generate --year 2024

    Note over App: drop copies, screenshots, documents, hidden pictures
    App->>Immich: fetch previews and faces
    opt GPU or Full tier
        App->>Helpers: captions and detector checks (or run them locally)
    end
    Note over App: group moments into stories, pick shots, run the family-viewing check, trim to length
    alt nothing worth a film
        App-->>You: "Nothing worth a film" (no film, exit 0)
    else a cut
        Note over App: title: yours, a model's for people and occasion films, else a template
        Note over App: music: your file, generated, or a bundled track
        alt a render worker is set
            App->>Helpers: render job
            Helpers->>Immich: download the originals
        else render here
            App->>Immich: download the originals
            Note over App: FFmpeg assembles clips, titles and music
        end
        opt upload on
            App->>Immich: upload the film, tag it, add it to the album
        end
        App-->>You: the film and its run id
    end
