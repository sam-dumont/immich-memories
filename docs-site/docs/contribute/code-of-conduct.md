# Code of conduct

This project follows the [Contributor Covenant Code of Conduct v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The full text is in [CODE_OF_CONDUCT.md](https://github.com/sam-dumont/immich-memories/blob/main/CODE_OF_CONDUCT.md) in the repository root.

By participating in this project, you agree to uphold this standard. Report unacceptable behaviour through GitHub's private reporting form, or the other contact routes the code of conduct lists.
