Give Immich Memories its own app login before publishing its port on your trusted LAN. Under the
app service's existing `environment:` block, set:

```yaml
IMMICH_MEMORIES_AUTH_USERNAME: admin
IMMICH_MEMORIES_AUTH_PASSWORD: replace-with-your-own-long-password
```

Choose a password of at least 12 characters. In the same service's `ports:`, change
`127.0.0.1:8080:8080` to `0.0.0.0:8080:8080`. If the host already uses 8080, choose another host
port, for example `0.0.0.0:8081:8080`. The last number remains 8080.

This is the app's login; the container manager's account does not protect this port. These
settings use HTTP on your LAN. For HTTPS or private access through localhost, use the
[other access routes](../docker.md#reaching-the-ui-from-another-machine).
