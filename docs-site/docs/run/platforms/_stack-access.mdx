The app asks for a sign-in either way. To open it to your trusted LAN, tick **Open the UI to
other machines on my LAN** in the builder above. Leave the login empty to get a generated password
(read it with `docker logs immich-memories` or in the container's log view), or enter a username
and a password of at least 12 characters and the generated file carries them.

To do it by hand, edit the lines the file already has. Do not add a second copy: Compose refuses a
file that defines the same key twice. To pick your own login, change the two empty values under the
app service's `environment:` block:

```yaml
IMMICH_MEMORIES_AUTH_USERNAME: admin
IMMICH_MEMORIES_AUTH_PASSWORD: replace-with-your-own-long-password
```

The password needs at least 12 characters. To publish the port, in the same service's `ports:` change
<code>127.0.0.1:<ComposePort />:8080</code> to <code>0.0.0.0:<ComposePort />:8080</code>. If the host already uses <ComposePort />, choose another host
port, for example `0.0.0.0:22831:8080`. The last number remains 8080.

This is the app's login; the container manager's account does not protect this port. These
settings use HTTP on your LAN. For HTTPS or private access through localhost, use the
[other access routes](../docker.md#reaching-the-ui-from-another-machine).
